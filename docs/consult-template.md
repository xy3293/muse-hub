# 咨询模板（C11 附注）

卡住时向 ChatGPT 网页版（主通道）提问，必须按下面模板发问；拿到回答后按过滤规则压缩。

## 发问模板（逐字用，替换括号内容）

```
我在做。
约束（必须遵守）：不新增服务器、不新增凭据、不改现有底座、只能用现有数据。
问题：。
请只输出下面五段，不要任何前言、背景复述、免责声明、"取决于"：
1) 结论：直接给一个推荐做法（一句话）
2) 备选：最多 2 个，每个一行
3) 代价：推荐做法的代价（一行）
4) 风险：最可能翻车的一种情况（一行）
5) 不要做：明确劝退的 1–2 件事（一行）
总共不超过 200 字。
```

## 答案过滤规则（拿到回复后自己做）

- 若回答超过 200 字 → 自己压到 5 行，**原文不要贴进报告**；
- 若出现"建议咨询专业人士/法律/合规""这取决于""需要更多信息才能判断"→ 视为无效答案，换一种问法重问一次（明确说"我已经有授权，只需要技术取舍，不要合规建议"）；
- 若它拒答或绕圈 → 降级到 Codex，并在报告里记一句"主通道未给出可用方案"。

## 写进报告的口径

咨询记录只写三行：**问了什么（一句）→ 得到什么结论（一句）→ 你怎么定的（一句）**。不要贴长回答，不要贴对话原文。

## 边界

- 模板里的约束（不新增服务器/凭据、不改底座、只用现有数据）是系统真实约束，每次提问都带上。
- 咨询不贴凭据、token、私钥、真实账号、客户数据；不上传整份仓库文件。C1 不变。
