## 验收标准

- [ ] 覆盖以下 6 类，缺一类验收不通过（每类至少 2 个具体产品/服务，每个都给：给什么、额度/上限、有效期、要不要信用卡/手机验证、有无自动扣费陷阱）：
  1. 免费 GPU / TPU 算力（Kaggle 除外，至少含 Colab 免费档及其他 1 个）
  2. 免费云额度 / 免费云主机（例如 AWS / GCP / Azure / Oracle 等免费层，注明是永久免费层还是限时试用）
  3. 免费 LLM API 额度（例如 Groq / Cerebras / OpenRouter 免费档 / 各厂商免费 API 等，注明模型、速率限制、是否会过期）
  4. 免费开发 / 协作工具（与 Chen 的 GitHub / 代码 / 文档工作相关，注明免费档上限）
  5. 免费数据 / 行情数据（与回测相关：股票、加密，注明延迟、覆盖、调用上限）
  6. 其他可能相关的免费资源（例如免费存储、免费域名 / 隧道、免费监控等，挑与 Chen 相关的写，不相关的不写）
- [ ] 每个产品给一个对 Chen 的有用度评级（高 / 中 / 低 / 无）+ 一句话理由，理由必须挂钩上文“实际需求”里的具体一点（例如“回测是 CPU 活，所以 GPU 类一律不高”），不许只写“很好用”。
- [ ] 最后给一张总表 + 推荐清单：值得试的最多 3 个，按优先级排序，每个写第一步做什么、要准备什么、预计花多少时间；不值得的写清为什么不试。
- [ ] 所有数字注明日期与来源，可复核；事实与推断分开写，不确定的已标注“未验证”；明确区分“永久免费”与“限时试用 / 首年免费”，后者必须写清到期后会发生什么（自动扣费 / 降级 / 停用）。
